# Simulador de Caixa Eletrônico

Projeto desenvolvido em linguagem C para simular saques em um caixa eletrônico.

## Funcionalidades
- Saldo inicial de R$ 1.000,00
- Validação de saldo insuficiente
- Verificação de valores múltiplos de 5
- Cálculo das notas de R$ 100, R$ 50, R$ 20, R$ 10 e R$ 5

## Tecnologias
- Linguagem C
- Biblioteca stdio.h

## Como utilizar
Execute o arquivo `main.c` em um ambiente com compilador C e informe o valor do saque.
